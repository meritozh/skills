# Experience first

Apply when a product, UX, API, or scope trade-off comes up.

- When the builder's convenience and the user's experience conflict, choose the experience.
- Every feature, control, and option justifies itself. A polished three beats a rough ten.
- The details are the feature: feedback, error states, empty states, alignment, transitions.
- The user is whoever consumes the work: the end user of a screen, the developer who imports a library, the engineer who maintains the code next.
