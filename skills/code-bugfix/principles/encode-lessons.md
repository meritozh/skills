# Encode lessons in structure

Apply when you write the same instruction a second time, or make the same correction twice.

- Turn the rule into structure: a lint, a test, a check in a script, a type, a field in a template.
- When the fix is structural, use only the structure. The repeated instruction was the symptom.
- When the lesson needs judgment and cannot be checked by a tool, make it prominent and add an example of the failure.
