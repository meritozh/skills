# Attack the premise

Apply when two fixes that rest on one premise have failed the same check: a test, a review round, a battle, a blocked step.

- Write the premise down: the one sentence every failed fix assumed.
- Test it before the next fix. Find an observation that comes out differently when the premise is false, and make it. Look at how the failures are spread, not only at how many there are.
- When the evidence contradicts the premise, find what the failures share that the premise did not predict, and change that.

Do not start a third fix before the premise is written down and tested.
