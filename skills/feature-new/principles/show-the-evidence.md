# Show the evidence

Apply to every claim in a report, an objection, a finding, a PR, or a doc.

- Each claim carries its source: a file and line, a command and its output, a doc and its line.
- A claim without a source is labeled: `measured` (you ran it), `read` (you read it in this session), `inferred` (it follows from what you read), or `guess`.
- Cite only what you read in this session. A file, a skill, or a principle you remember is not a source until you open it.
- Never hand the user a check you could run yourself.
