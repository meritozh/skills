# Compare real options

Apply when a decision has no precedent in the codebase: a new interaction, a new architecture, a choice that depends on feel.

- Produce two or three options that differ in structure, not in detail, and compare them side by side before committing.
- A question that running something can settle is settled by running it: a prototype, a spike, a benchmark. Argue only about what no run can show.
- Keep the best option set aside, with the condition under which it would win.
